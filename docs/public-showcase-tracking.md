# Tracking pointer

Linear is the source of truth for scope, status, dependencies and completion
evidence. This page only points there; do not keep a second checklist in the
repository.

- Project: **Diplomacy — daily challenge showcase MVP** (Linear, team Dickielabs)
- Start-here document for any contributor or coding agent:
  [Daily-challenge MVP — agent handoff, implementation plan and release gates](https://linear.app/dickielabs/document/daily-challenge-mvp-implementation-plan-and-release-gates-488997679a3e)

Issue identifiers (`DIC-nn`) quoted in code comments, commit messages and these
docs refer to that project. Each issue states what is already implemented, what
remains, and its acceptance criteria; several are umbrella issues that stay open
until a later integration lands.

Working agreement recorded there: claim an issue in Linear with branch, base
commit and files before editing; one scoped pull request per slice; hand off
with commit, tests run and what remains. Paid provider calls, live notification
email, deployment and publication each need the owner's explicit authorization.

The [September 2026 technical review](public-showcase-review.md) that led to the
plan is kept as history.
